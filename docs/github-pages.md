# GitHub publication

This export contains the published birthday site from source commit `132937c91e2fa68228317baa9d75fe03fbf03c8f`, with portable asset paths for a GitHub Pages project URL. Source HTML, CSS, dynamic photographs, chess pieces and the Stockfish Worker all use relative local URLs. Font and engine licenses are retained. No secrets or hosting credentials are included.

1. Push the source to the repository's `main` branch.
2. In Settings > Pages, choose GitHub Actions as the publishing source. The repository and account must support Pages.
3. Run the `Build and publish birthday gift` workflow from Actions to deploy the first version.
4. For automatic deployment on subsequent pushes, add the repository Actions variable `PAGES_ENABLED` with value `true`.

Every push runs the production build and the real Stockfish integration check, including when automatic publication is disabled. GitHub Pages settings, repository visibility and live deployment are not configured by this local preparation.

The calendar opens on November 14. It is a birthday puzzle, not an access control. Letter drafts stay in the visitor's browser. Email delivery still depends on FormSubmit and recipient activation; it was not verified during this export.
